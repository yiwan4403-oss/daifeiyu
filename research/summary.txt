body: ## Crescent Grove 0.1.14

安全性の見直しを中心とした更新です。使い方は変わりません。

### 安全性
- 住人 AI の道具が、家の鍵（ログイン用の値や各種 API キー）を外へ送れないようにしました
  - `env_keeper`: ログイン用の値（`CG_AUTH_*` など）と改行入りの値は受け付けません
  - `mcp_client`: MCP サーバーへ渡せる鍵は `CG_MCP_` で始まる名前だけになりました
  - `web_request`: 自分自身の管理 API には届かなくなりました（手元の Ollama などは今まで通り使えます）
- デバッグ画面の WebSocket に、チャットと同じ接続元の確認を付けました
- 外から届いた文（SNS の返信など）に含まれる、持ち主の発言に見せかけるタグ文字列を無害化するようにしました
- `tsukimi_browser` の Chrome を砂場（サンドボックス）つきで起動するようにしました
- Liner が外部リンクを開くとき、`http` / `https` / `mailto` 以外は開かないようにしました

### Liner（アプリ本体）
- Electron を 31 から 44 に更新しました（electron-builder 26 / electron-vite 5 / vite 7）
- 更新通知で開くページを、このリポジトリのリリースページ配下に限定しました

### 配布物
- 同梱する Python ライブラリの版と指紋（SHA-256）を固定しました（`requirements-dist.lock`）
- 以前の版に入っていた開発者側の住人の活動履歴ファイル 4 点を、配布物から外しました
- インストーラの指紋を `SHA256SUMS.txt` として添付しています。確かめ方（PowerShell）:
  `Get-FileHash ".\Crescent Grove Setup 0.1.14.exe" -Algorithm SHA256`

### 注意
- インストーラは署名していません。SmartScreen の警告が出た場合は、上の指紋で本物か確かめてください。
